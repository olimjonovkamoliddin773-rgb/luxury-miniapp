# LUXURY

### Premium Footwear — Telegram Mini App

LUXURY is a premium footwear shopping experience inside Telegram.

## Features

- Premium footwear catalog
- Product search
- Categories and filters
- Product photos
- Size selection
- Shopping cart
- Checkout
- Orders
- Online payment
- Delivery / pickup
- BILLZ integration
- Admin panel

## Project

Telegram Mini App for the LUXURY footwear store.
